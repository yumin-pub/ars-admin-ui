# Table

Table 컴포넌트는 공통 테이블 UI를 제공합니다.

컬럼(Column)과 데이터(Data)를 분리하여 관리하며, 제네릭(Generic)을 사용해 행(Row) 타입을 안전하게 지정할 수 있습니다.

---

## Overview

Table은 동일한 테이블 구조를 여러 화면에서 재사용하기 위한 컴포넌트입니다.

컬럼 정의와 실제 데이터를 분리하고, 각 컬럼의 `render`를 통해 Badge, Button, Checkbox 등 원하는 UI를 셀에 렌더링할 수 있습니다.

```tsx
<Table<BasicRow>
  columns={columns}
  data={data}
/>
```

기본 구조는 다음과 같습니다.

```html
<div class="ui-table-wrap">
  <table class="ui-table">
    <thead class="ui-table__head">
      <tr>
        <th scope="col" class="ui-table__cell-sm">번호</th>
        <th scope="col">제목</th>
        <th scope="col" class="ui-table__cell-md">상태</th>
        <th scope="col" class="ui-table__cell-md">등록일</th>
      </tr>
    </thead>

    <tbody class="ui-table__body">
      <tr>
        <td>1</td>
        <td>긴급공지 안내</td>
        <td>노출중</td>
        <td>2026-06-10</td>
      </tr>
    </tbody>
  </table>
</div>
```

---

## Features

- 컬럼(Column)과 데이터(Data) 분리
- 제네릭을 이용한 Row 타입 지정
- `dataIndex`를 통한 데이터 매핑
- `render`를 통한 Custom Cell 렌더링
- 컬럼 너비 지정
- 컬럼 정렬 지정
- Loading 상태 지원
- Empty 상태 지원
- Empty Message 커스텀 지원
- 추가 Table 클래스 적용 가능
- HTML 클래스 방식과 React 컴포넌트 방식 지원

## TableRow

모든 Table 행 데이터는 최소한 `id` 값을 가져야 합니다.

```tsx
interface TableRow {
  id: number | string;
}
```

실제 화면에서는 `TableRow`를 확장하여 필요한 데이터 구조를 정의합니다.

```tsx
interface BasicRow extends TableRow {
  id: number;
  title: string;
  status: 'exposed' | 'hidden';
  date: string;
}
```

`id`는 각 행의 React `key`로 사용됩니다.

---

## TableColumn

컬럼은 `TableColumn<T>` 타입으로 정의합니다.

```tsx
const columns: TableColumn<BasicRow>[] = [
  {
    dataIndex: 'id',
    title: '번호',
  },
  {
    dataIndex: 'title',
    title: '제목',
  },
  {
    dataIndex: 'status',
    title: '상태',
  },
  {
    dataIndex: 'date',
    title: '등록일',
  },
];
```

### Column Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataIndex` | `keyof T` | - | Row 데이터에서 사용할 필드 |
| `title` | `ReactNode` | - | 컬럼 헤더에 표시할 콘텐츠 |
| `width` | `string` | - | 컬럼 너비 |
| `align` | `'left' \| 'center' \| 'right'` | - | 컬럼 정렬 |
| `render` | `(value, row, index) => ReactNode` | - | 셀 커스텀 렌더링 |

---

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `TableColumn<T>[]` | - | 테이블 컬럼 정의 |
| `data` | `T[]` | - | 테이블 행 데이터 |
| `emptyMessage` | `ReactNode` | `'검색 결과가 없습니다.'` | 데이터가 없을 때 표시할 콘텐츠 |
| `loading` | `boolean` | `false` | 데이터 로딩 상태 |
| `refreshing` | `boolean` | `false` | 다시 불러오는 상태. 행은 유지하고 Loading overlay를 덮음. `loading`이 `true`면 무시 |
| `refreshingMessage` | `string` | `'데이터를 불러오는 중입니다.'` | refreshing overlay 문구 |
| `selectedIds` | `Array<TableRow['id']>` | `[]` | 선택된 행의 id 목록. 해당 행에 `is-selected` 클래스를 붙임 |
| `ariaLabel` | `string` | - | `table`의 `aria-label`. 지정하지 않으면 속성을 만들지 않음 |
| `caption` | `ReactNode` | - | 표 제목(`<caption class="ui-table__caption">`). 지정하지 않거나 `null` / `''` / `false`이면 요소를 만들지 않음 (`0`은 표시) |
| `className` | `string` | `''` | `table` 요소에 추가할 클래스 |

## React Component Usage

### Basic Table

```tsx
interface BasicRow extends TableRow {
  id: number;
  title: string;
  status: 'exposed' | 'hidden';
  date: string;
}

const columns: TableColumn<BasicRow>[] = [
  {
    dataIndex: 'id',
    title: '번호',
  },
  {
    dataIndex: 'title',
    title: '제목',
  },
  {
    dataIndex: 'status',
    title: '상태',
  },
  {
    dataIndex: 'date',
    title: '등록일',
  },
];

const data: BasicRow[] = [
  {
    id: 1,
    title: '긴급공지 안내',
    status: 'exposed',
    date: '2026-06-10',
  },
  {
    id: 2,
    title: '시스템 점검 안내',
    status: 'hidden',
    date: '2026-06-12',
  },
];

<Table<BasicRow>
  columns={columns}
  data={data}
/>
```

## Custom Cell

`render`를 사용하면 원본 데이터를 원하는 UI로 변경하여 렌더링할 수 있습니다.

```tsx
import { Badge } from '@/components/Badge';

const columns: TableColumn<BasicRow>[] = [
  {
    dataIndex: 'status',
    title: '상태',
    render: (value) => (
      <Badge variant={value === 'exposed' ? 'success' : 'neutral'}>
        {value === 'exposed' ? '노출중' : '미노출'}
      </Badge>
    ),
  },
];
```

`render`는 다음 값을 전달받습니다.

```text
value
= 현재 셀의 원본 값

row
= 현재 행 전체 데이터

index
= 현재 행의 순서
```

## Action Cell

별도의 Raw 데이터가 필요하지 않은 액션 컬럼에서는 기존 `dataIndex`를 재사용하고 `render`로 UI를 구성할 수 있습니다.

```tsx
{
  dataIndex: 'id',
  title: '관리',
  render: () => (
    <div className="ui-table__actions">
      <Button
        variant="outline"
        color="neutral"
        size="md"
      >
        수정
      </Button>

      <Button
        variant="outline"
        color="neutral"
        size="md"
      >
        삭제
      </Button>
    </div>
  ),
}
```

## Selectable Table

Checkbox를 `render`에서 사용하고, 선택된 행의 id를 `selectedIds`로 전달하면 선택된 행이 강조됩니다.
선택 상태는 Table이 아니라 **사용하는 쪽(부모)이 관리**합니다.

```tsx
interface SelectableRow extends TableRow {
  id: number;
  title: string;
  status: 'exposed' | 'hidden' | 'scheduled';
  date: string;
}
```

```tsx
const [selectedIds, setSelectedIds] = useState<number[]>([1]);

const toggleRow = (id: number) => {
  setSelectedIds((prev) =>
    prev.includes(id)
      ? prev.filter((selectedId) => selectedId !== id)
      : [...prev, id],
  );
};

const columns: TableColumn<SelectableRow>[] = [
  {
    dataIndex: 'id',
    title: '선택',
    width: '56px',
    align: 'center',
    render: (_, row) => (
      <Checkbox
        id={`table-row-${row.id}`}
        aria-label={`${row.id}번 항목 선택`}
        checked={selectedIds.includes(row.id)}
        onChange={() => toggleRow(row.id)}
      />
    ),
  },
];
```

```tsx
<Table<SelectableRow>
  className="ui-table--selectable"
  columns={columns}
  data={data}
  selectedIds={selectedIds}
/>
```

선택된 행에는 `is-selected` 클래스가 붙어 배경색과 왼쪽 강조 막대가 표시됩니다.

## Empty State

`data`가 비어 있으면 Empty 상태를 자동으로 렌더링합니다.

```tsx
<Table<BasicRow>
  columns={columns}
  data={[]}
/>
```

기본 메시지는 다음과 같습니다.

```text
검색 결과가 없습니다.
```

`emptyMessage`를 전달하여 변경할 수 있습니다.

```tsx
<Table<BasicRow>
  columns={columns}
  data={[]}
  emptyMessage="등록된 데이터가 없습니다."
/>
```

## Loading State

`loading`이 `true`이면 데이터 대신 로딩 상태를 표시합니다.

```tsx
<Table<BasicRow>
  columns={columns}
  data={[]}
  loading
/>
```

표시되는 기본 문구:

```text
데이터를 불러오는 중입니다.
```

`loading` 상태에서는 실제 데이터 렌더링보다 Loading 상태가 우선합니다.

## Refreshing State

페이지 이동처럼 **이미 보이는 데이터를 유지한 채** 새 데이터를 기다릴 때 `refreshing`을 씁니다.

```tsx
<Table<BasicRow>
  columns={columns}
  data={rows}               // 이전 목록 그대로
  refreshing={isPlaceholderData}
  refreshingMessage="다음 페이지를 불러오는 중입니다."
/>
```

`true`일 때만 다음이 추가됩니다. `false`면 기존과 같은 DOM입니다.

```html
<div class="ui-table-wrap is-refreshing">
  <table class="ui-table" aria-busy="true">...</table>

  <div class="ui-table__refreshing" aria-hidden="true">
    <div class="ui-loading ui-loading--sm ui-loading--overlay" ...>...</div>
  </div>
</div>
```

- `loading`이 `true`이면 `refreshing`은 무시됩니다. (초기 로딩 문구가 우선)
- overlay는 시각 표시 전용입니다. 바쁜 상태는 `aria-busy`로 전달하고, 완료 안내는 화면의 결과 문구(`aria-live`)가 담당합니다.

### 한계

- **표 안의 조작 요소는 막지 않습니다.** overlay는 눈으로만 덮고 `aria-hidden` 래퍼에 들어 있어, refreshing 중에도 행 안의 버튼·체크박스에 Tab 포커스와 클릭이 됩니다. 이전 목록의 행을 수정·삭제하는 화면이라면 사용하는 쪽에서 막아야 합니다. (`inert` 적용 여부는 CRUD 2단계에서 정합니다.)
- **가로 스크롤 시 처음 보이는 폭만 덮습니다.** overlay는 `.ui-table-wrap` 기준 `position: absolute; inset: 0`이라, 표가 `min-width: 800px`보다 좁은 화면에서 가로 스크롤되면 스크롤해서 드러난 오른쪽 부분은 덮이지 않습니다.

## Table Name

표에는 스크린리더가 읽을 이름을 붙입니다. 화면에 제목을 보여줄지에 따라 둘 중 하나를 씁니다.

- 보이는 제목이 필요하면 `caption`: `<caption class="ui-table__caption">`이 생깁니다.
- 바깥에 이미 제목이 있거나 제목을 보이지 않으려면 `ariaLabel`: `<table aria-label="...">`이 됩니다.

둘 다 지정하지 않으면 기존과 같은 DOM이 렌더링됩니다. `caption`에 `null`, `''`, `false`를 넘겨도 안 넘긴 것과 같고, `0`은 그대로 표시됩니다.

```tsx
<Table<BasicRow> columns={columns} data={data} caption="공지사항 목록" />

<Table<BasicRow> columns={columns} data={data} ariaLabel="공지사항 목록" />
```

## Column Width

Table은 **제목 칸만 남는 폭을 채우고, 나머지 칸은 고정 px 폭**을 가집니다.
화면 해상도가 바뀌어도 번호·상태·등록일·관리 칸의 폭은 변하지 않습니다.

### React

`width`로 컬럼 폭을 지정합니다. `width`를 지정하지 않은 컬럼(보통 제목)이 남는 폭을 차지합니다.

```tsx
const columns: TableColumn<BasicRow>[] = [
  {
    dataIndex: 'id',
    title: '번호',
    width: '80px',
  },
  {
    dataIndex: 'title',
    title: '제목', // width 없음 → 남는 폭
  },
  {
    dataIndex: 'status',
    title: '상태',
    width: '120px',
  },
];
```

### HTML

`<th>`에 폭 클래스를 붙입니다. 폭은 첫 줄(헤더)의 `<th>` 기준으로 정해집니다.

| Class | Width | 용도 |
| --- | --- | --- |
| `ui-table__cell-sm` | 80px | 번호 |
| `ui-table__cell-md` | 120px | 상태, 등록일 |
| `ui-table__cell-lg` | 160px | 관리(버튼 2개) |
| `ui-table__cell-checkbox` | 56px | 선택(체크박스) |

```html
<th scope="col" class="ui-table__cell-sm">번호</th>
<th scope="col">제목</th>
<th scope="col" class="ui-table__cell-md">상태</th>
<th scope="col" class="ui-table__cell-md">등록일</th>
<th scope="col" class="ui-table__cell-lg">관리</th>
```

### 반응형

표의 최소 폭은 `800px`입니다. 화면이 이보다 좁아지면 표가 줄어들지 않고 `ui-table-wrap` 안에서 **가로 스크롤**됩니다.

## Class Structure

```text
ui-table-wrap
├── is-refreshing           // 다시 불러오는 중 (position: relative)
├── ui-table__refreshing    // overlay 래퍼 (aria-hidden)
└── ui-table
    ├── ui-table--selectable
    ├── ui-table__caption
    ├── ui-table__head
    │   └── th
    └── ui-table__body
        └── tr
            ├── td
            ├── ui-table__cell-title
            ├── ui-table__cell-sm / md / lg
            ├── ui-table__cell-checkbox
            ├── ui-table__actions
            └── ui-table__empty
```

상태 클래스:

```text
is-selected   // 선택된 행: 배경색 + 왼쪽 강조 막대
```

상태 셀의 `ui-badge`는 별도 컴포넌트입니다. 클래스 구조와 색상 기준은 [Badge](?path=/docs/components-badge--docs) 문서를 참고하세요.

## Accessibility

- Table Header에는 `<th scope="col">`을 사용합니다.
- 표 이름은 `caption`(보이는 제목) 또는 `ariaLabel`(보이지 않는 이름)로 제공합니다. 둘 중 하나만 씁니다.
- 각 Row는 고유한 `id` 값을 가져야 합니다.
- 선택 가능한 Table의 Checkbox에는 해당 행을 식별할 수 있는 `aria-label`을 제공합니다.
- Empty / Loading 상태에서도 동일한 `<table>` 구조를 유지합니다.
- `refreshing` 중에는 `<table aria-busy="true">`가 됩니다. overlay의 Loading은 `role="status"` live 영역이라, 화면의 결과 안내와 두 번 읽히지 않도록 `aria-hidden` 래퍼 안에 둡니다. 완료 안내가 필요하면 표 바깥에 `aria-live` 문구를 둡니다. (예: 게시글 관리의 "총 N건 · M페이지 중 K페이지")
- `render`를 통해 Button이나 Checkbox를 렌더링할 경우 해당 컴포넌트의 접근성 속성을 함께 제공합니다.

Checkbox 예시:

```tsx
<Checkbox
  id={`table-row-${row.id}`}
  aria-label={`${row.id}번 항목 선택`}
/>
```

## Notes

- 모든 Row 타입은 `TableRow`를 확장하고 `id`를 가져야 합니다.
- `dataIndex`는 실제 Row 타입에 존재하는 key만 지정할 수 있습니다.
- `title`과 `emptyMessage`는 `ReactNode`를 지원합니다.
- `render`를 사용하면 Badge, Button, Checkbox 등 다양한 UI를 셀에 출력할 수 있습니다.
- `className`은 기본 `ui-table` 클래스 뒤에 추가됩니다.
- 컬럼 폭을 지정하지 않으면 해당 컬럼들이 남는 폭을 나눠 가집니다. 제목처럼 늘어나야 하는 컬럼 하나만 비워두는 것을 권장합니다.
- 행 선택 상태는 `selectedIds`로 전달합니다. 체크박스 상태를 관리하는 것은 사용하는 쪽의 몫입니다.
- 시각 예제는 `TablePage.tsx`에서 관리하며 Storybook에서는 `Examples`를 통해 재사용합니다.
