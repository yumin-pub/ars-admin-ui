# Loading

Loading은 데이터를 불러오거나 저장하는 동안 진행 중임을 알리는 상태 표시입니다.

Spinner와 안내 문구를 패널에 담아 보여주며, `overlay`로 영역 전체를 덮을 수 있습니다.

---

## Overview

```tsx
<Loading overlay={false} />
```

기본 구조는 다음과 같습니다.

```html
<div class="ui-loading ui-loading--md" role="status" aria-live="polite" aria-busy="true">
  <div class="ui-loading__panel">
    <span class="ui-loading__spinner" aria-hidden="true"></span>

    <div class="ui-loading__content">
      <p class="ui-loading__message">데이터를 불러오는 중입니다.</p>
      <p class="ui-loading__description">잠시만 기다려 주세요.</p>
    </div>
  </div>
</div>
```

---

## Features

- `sm` / `md` / `lg` 3가지 크기
- `overlay`로 기준 영역 전체를 dimmed 처리 (기본값 `true`)
- 기본 문구 / 보조 문구 변경, 보조 문구 생략(`description={null}`)
- `prefers-reduced-motion` 환경에서 회전 속도를 늦춤
- HTML 클래스 방식과 React 컴포넌트 방식 지원

---

## Import

```tsx
import { Loading } from '@/components/Loading';

import type { LoadingProps, LoadingSize } from '@/components/Loading';
```

기존 직접 경로(`components/Loading/Loading`)의 default import도 계속 동작합니다.

---

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `overlay` | `boolean` | `true` | 가장 가까운 `position` 기준 영역 전체를 dimmed overlay로 덮음 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Spinner·패널 크기 |
| `message` | `string` | `'데이터를 불러오는 중입니다.'` | 기본 안내 문구. 빈 문자열이면 표시하지 않음 |
| `description` | `string \| null` | `'잠시만 기다려 주세요.'` | 보조 안내 문구. `undefined`일 때만 기본값, `null`이면 표시하지 않음 |
| `className` | `string` | `''` | 루트 요소에 추가할 클래스 |

## States

| State | 사용 | 결과 |
| --- | --- | --- |
| 기본 | `<Loading />` | 기본 문구 + 보조 문구 |
| 보조 문구 없음 | `description={null}` | 기본 문구만 표시 |
| Spinner만 | `message="" description={null}` | 문구 영역(`ui-loading__content`) 없이 Spinner만 표시 |
| Overlay | `overlay` (기본값) | 기준 영역 위를 `rgba($gray-900, .42)`로 덮음 |

### NoDescription

<Canvas of={LoadingStories.NoDescription} />

```tsx
<Loading size="sm" message="다음 페이지를 불러오는 중입니다." description={null} />
```

`description=""`도 표시되지 않지만, "의도적으로 비움"을 드러내기 위해 `null`을 권장합니다.

## Overlay

`overlay`는 `position: absolute; inset: 0`이므로 **덮을 영역에 `position: relative`가 있어야** 합니다.

```tsx
<div style={{ position: 'relative' }}>
  {/* 내용 */}
  <Loading size="sm" />
</div>
```

## Accessibility

- 루트는 `role="status"` + `aria-live="polite"`라서 나타날 때 문구를 스크린리더가 읽습니다.
- Spinner는 `aria-hidden="true"` 장식 요소입니다. 의미는 문구로 전달합니다.
- 같은 내용을 알리는 다른 live 영역이 이미 있으면 중복 낭독됩니다. 한쪽만 남깁니다. (예: Table의 `refreshing`은 overlay를 `aria-hidden` 래퍼에 넣어 화면의 결과 안내만 읽히게 합니다.)
- Spinner만 표시할 때(문구 없음)는 읽을 내용이 없으므로, 바깥 영역에 `aria-busy` 또는 별도 안내 문구를 둡니다.
- `prefers-reduced-motion: reduce`에서는 회전 속도를 절반으로 늦춥니다.
