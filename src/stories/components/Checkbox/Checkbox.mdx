# Checkbox

사용자가 하나 이상의 항목을 선택할 수 있는 체크박스 컴포넌트입니다.

HTML 클래스 방식과 React 컴포넌트 방식을 모두 지원하며, Wrap 구조와 Detached 구조를 제공합니다.

---

## Overview

Checkbox는 여러 개의 항목 중 하나 이상을 선택해야 하는 경우 사용합니다.

기본 구조는 `wrap`이며, 필요에 따라 `detached` 구조를 사용할 수 있습니다.

```tsx
<Checkbox>
  Checkbox
</Checkbox>
```

렌더링되는 기본 클래스 구조는 다음과 같습니다.

```html
<label class="ui-checkbox ui-checkbox--wrap">
  <input type="checkbox" class="ui-checkbox__input" />
  <span class="ui-checkbox__control"></span>
  <span class="ui-checkbox__label">Checkbox</span>
</label>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | - | 체크박스 라벨 |
| `children` | `ReactNode` | - | label 대신 사용할 콘텐츠 |
| `structure` | `'wrap' \| 'detached'` | `'wrap'` | 체크박스 구조 |
| `checked` | `boolean` | - | 체크 여부 |
| `disabled` | `boolean` | `false` | 비활성화 여부 |
| `id` | `string` | - | Detached 구조에서 label 연결용 id |
| `className` | `string` | `''` | 추가 클래스 |

`CheckboxProps`는 `InputHTMLAttributes<HTMLInputElement>`를 확장하므로 기본 input 속성을 함께 사용할 수 있습니다.

## HTML Class Usage

### Wrap

```html
<label class="ui-checkbox ui-checkbox--wrap">
  <input type="checkbox" class="ui-checkbox__input" />
  <span class="ui-checkbox__control"></span>
  <span class="ui-checkbox__label">Checkbox</span>
</label>
```

### Detached

```html
<span class="ui-checkbox ui-checkbox--detached">
  <input
    id="checkbox"
    type="checkbox"
    class="ui-checkbox__input"
  />

  <label
    class="ui-checkbox__wrapper"
    for="checkbox"
  >
    <span class="ui-checkbox__control"></span>
    <span class="ui-checkbox__label">Checkbox</span>
  </label>
</span>
```

## Accessibility

- `wrap` 구조에서는 `label`이 input을 감싸므로 체크박스와 라벨이 연결됩니다.
- `detached` 구조에서는 반드시 `id`를 전달하여 input의 `id`와 label의 `htmlFor`를 연결합니다.
- 라벨 콘텐츠가 없는 경우 `aria-label` 또는 `aria-labelledby`를 제공합니다.
- 비활성화 상태는 HTML 기본 `disabled` 속성을 사용합니다.

예시

```tsx
<Checkbox
  aria-label="전체 선택"
/>
```

---

## Notes

- `wrap`은 input을 label이 감싸는 구조입니다.
- `detached`는 input과 label이 분리된 구조입니다.
- 시각 예제는 `CheckboxPage.tsx`에서 관리하며 Storybook에서는 `Examples`를 통해 재사용합니다.
