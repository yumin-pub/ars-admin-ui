# Input

사용자로부터 텍스트를 입력받는 기본 입력 컴포넌트입니다.

HTML 클래스 방식과 React 컴포넌트 방식을 모두 지원하며, 다양한 상태와 레이아웃을 제공합니다.

---

## Overview

Input은 일반적인 텍스트 입력뿐 아니라 상태 표시, Helper Message, Prefix/Suffix, Counter 등 실무에서 자주 사용하는 기능을 제공합니다.

```tsx
<Input
  label="이름"
  placeholder="이름을 입력하세요"
/>
```

기본 구조는 다음과 같습니다.

```html
<div class="ui-field ui-field--column">
  <div class="ui-field__content">
    <label class="ui-field__label">Label</label>

    <div class="ui-input ui-input--outline ui-input--md">
      <input
        class="ui-input__control"
        type="text"
      />
    </div>

    <div class="ui-field__meta">
      <p class="ui-field__message">Helper Message</p>
    </div>
  </div>
</div>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | - | Label |
| `helperText` | `ReactNode` | - | Helper Message |
| `helperTextId` | `string` | - | Helper Message 요소의 id. 지정하면 input의 `aria-describedby`에 연결된다. 지정하지 않으면 기존 DOM과 같다 |
| `ref` | `Ref<HTMLInputElement>` | - | 실제 `<input>` 요소의 ref (React 19의 일반 prop) |
| `counter` | `ReactNode` | - | Counter |
| `variant` | `'outline' \| 'underline' \| 'ghost'` | `'outline'` | Input 스타일 |
| `InputSize` | `'md' \| 'lg'` | `'md'` | Input 크기 |
| `layout` | `'column' \| 'row'` | `'column'` | Label 배치 |
| `state` | `'default' \| 'success' \| 'error'` | `'default'` | Input 상태 |
| `prefixContent` | `ReactNode` | - | Prefix 영역 |
| `suffixContent` | `ReactNode` | - | Suffix 영역 |
| `clearable` | `boolean` | `false` | Clear Button 표시 |
| `onClear` | `() => void` | - | Clear Button 클릭(Enter·Space 포함) 시 호출. 넘기지 않으면 버튼은 표시만 되고 아무 동작도 하지 않는다 |
| `disabled` | `boolean` | `false` | 비활성화 |
| `readOnly` | `boolean` | `false` | 읽기 전용 |
| `fieldClassName` | `string` | `''` | ui-field 추가 클래스 |
| `inputClassName` | `string` | `''` | ui-input 추가 클래스 |
| `className` | `string` | `''` | input 추가 클래스 |

`InputProps`는 `InputHTMLAttributes<HTMLInputElement>`를 확장하므로 기본 input 속성을 함께 사용할 수 있습니다.

## React Component Usage

### Basic

```tsx
<Input
  label="이름"
  placeholder="이름을 입력하세요"
/>
```

### Error

```tsx
<Input
  label="이메일"
  state="error"
  helperText="이메일 형식을 확인해주세요."
/>
```

### Success

```tsx
<Input
  label="닉네임"
  state="success"
  helperText="사용 가능한 닉네임입니다."
/>
```

### Prefix / Suffix

```tsx
<Input
  prefixContent="₩"
  suffixContent="원"
/>
```

### Counter

```tsx
<Input
  counter="3 / 10"
  clearable
/>
```

### Clearable (onClear)

`clearable`만 주면 버튼이 보이기만 합니다. 실제로 값을 지우려면 `onClear`를 함께 넘기고, 그 안에서 값을 비웁니다.
비활성(`disabled`)·읽기 전용(`readOnly`)일 때는 `onClear`가 호출되지 않습니다.

```tsx
const [value, setValue] = useState('');

<Input
  id="keyword"
  label="검색어"
  value={value}
  onChange={(event) => setValue(event.target.value)}
  clearable={value !== ''}
  onClear={() => setValue('')}
/>
```

### 오류 메시지 연결 (helperTextId)

`helperTextId`를 주면 helperText 요소에 그 id가 붙고, input의 `aria-describedby`에 연결됩니다.
스크린리더는 입력칸에 들어갈 때 라벨과 함께 오류 메시지를 읽어 줍니다.
이미 `aria-describedby`를 넘겼다면 그 값 뒤에 이어 붙습니다. helperText가 비어 있으면 연결하지 않습니다.

```tsx
<Input
  id="post-title"
  label="제목"
  state={error ? 'error' : 'default'}
  helperText={error}
  helperTextId="post-title-error"
/>
// → <input id="post-title" aria-invalid="true" aria-describedby="post-title-error">
//   <p class="ui-field__message" id="post-title-error">제목을 입력해 주세요.</p>
```

<Canvas of={InputStories.ErrorDescribed} />

### ref

React 19에서는 `ref`가 일반 prop입니다. 실제 `<input>` 요소를 가리키므로, 값을 지운 뒤나 제출 오류 때 포커스를 옮길 수 있습니다.

```tsx
const inputRef = useRef<HTMLInputElement>(null);

<Input ref={inputRef} id="keyword" label="검색어" />
// inputRef.current?.focus();
```

## Accessibility

- `id`를 전달하면 Label의 `htmlFor`와 input의 `id`가 연결됩니다.
- Error 상태에서는 `aria-invalid`를 제공합니다.
- `helperTextId`를 주면 오류·도움말 메시지가 `aria-describedby`로 입력과 연결됩니다.
- Clear Button에는 `aria-label`을 제공합니다.
- Clear Button은 native `button`이라 Tab으로 이동해 Enter·Space로 `onClear`를 실행할 수 있고, `:focus-visible` 표시가 있습니다.
- 값을 지운 뒤 포커스를 입력창으로 돌려주는 일은 사용하는 쪽에서 합니다. `ref`로 input 요소를 받아 `focus()`를 부릅니다.
- Disabled와 Readonly는 HTML 기본 속성을 사용합니다.

예시

```tsx
<Input
  id="email"
  label="이메일"
  state="error"
/>
```
