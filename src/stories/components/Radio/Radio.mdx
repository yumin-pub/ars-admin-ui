# Radio

사용자가 여러 개의 선택지 중 하나를 선택할 수 있는 라디오 버튼 컴포넌트입니다.

HTML 클래스 방식과 React 컴포넌트 방식을 모두 지원하며, Wrap 구조와 Detached 구조를 제공합니다.

---

## Overview

Radio는 동일한 `name`을 가진 그룹에서 하나의 항목만 선택해야 하는 경우 사용합니다.

기본 구조는 `wrap`이며, 필요에 따라 `detached` 구조를 사용할 수 있습니다.

```tsx
<Radio name="radio-group">
  Radio
</Radio>
```

렌더링되는 기본 클래스 구조는 다음과 같습니다.

```html
<label class="ui-radio ui-radio--wrap">
  <input
    type="radio"
    class="ui-radio__input"
    name="radio-group"
  />
  <span class="ui-radio__control"></span>
  <span class="ui-radio__label">Radio</span>
</label>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | - | 라디오 라벨 |
| `children` | `ReactNode` | - | label 대신 사용할 콘텐츠 |
| `structure` | `'wrap' \| 'detached'` | `'wrap'` | 라디오 구조 |
| `checked` | `boolean` | `false` | 선택 여부 |
| `disabled` | `boolean` | `false` | 비활성화 여부 |
| `id` | `string` | - | Detached 구조에서 label 연결용 id |
| `name` | `string` | - | 같은 그룹을 묶는 name |
| `className` | `string` | `''` | 추가 클래스 |

`RadioProps`는 `InputHTMLAttributes<HTMLInputElement>`를 확장하므로 기본 input 속성을 함께 사용할 수 있습니다.

## React Component Usage

### Wrap

```tsx
<Radio name="radio-group">
  Radio
</Radio>
```

### Detached

```tsx
<Radio
  id="radio-default"
  name="radio-group"
  structure="detached"
>
  Radio
</Radio>
```

### Checked

```tsx
<Radio
  name="radio-group"
  defaultChecked
>
  Checked
</Radio>
```

### Disabled

```tsx
<Radio
  name="radio-group"
  disabled
>
  Disabled
</Radio>
```

## HTML Class Usage

### Wrap

```html
<label class="ui-radio ui-radio--wrap">
  <input
    type="radio"
    class="ui-radio__input"
    name="radio-group"
  />
  <span class="ui-radio__control"></span>
  <span class="ui-radio__label">Radio</span>
</label>
```

### Detached

```html
<span class="ui-radio ui-radio--detached">
  <input
    id="radio-default"
    type="radio"
    class="ui-radio__input"
    name="radio-group"
  />

  <label
    class="ui-radio__wrapper"
    for="radio-default"
  >
    <span class="ui-radio__control"></span>
    <span class="ui-radio__label">Radio</span>
  </label>
</span>
```

## Accessibility

- 동일한 그룹의 Radio는 같은 `name`을 사용합니다.
- `detached` 구조에서는 `id`와 `htmlFor`를 함께 사용합니다.
- 라벨이 없는 경우 `aria-label`을 제공합니다.
- 비활성화 상태는 `disabled` 속성을 사용합니다.

예시

```tsx
<Radio
  name="sort"
  aria-label="최신순"
/>
```

---

## Notes

- `wrap`은 input을 label이 감싸는 구조입니다.
- `detached`는 input과 label이 분리된 구조입니다.
- 같은 그룹의 Radio는 반드시 동일한 `name`을 사용해야 하나만 선택됩니다.
- 시각 예제는 `RadioPage.tsx`에서 관리하며 Storybook에서는 `Examples`를 통해 재사용합니다.
