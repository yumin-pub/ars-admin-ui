# Pagination

Pagination은 여러 페이지의 데이터를 탐색하기 위한 컴포넌트입니다.

현재 페이지를 기준으로 페이지 번호를 표시하며, 첫 페이지, 이전 페이지, 다음 페이지, 마지막 페이지로 이동할 수 있습니다.

---

## Overview

Pagination은 전체 페이지 수와 현재 페이지를 기준으로 표시할 페이지 번호 범위를 자동으로 계산합니다.

표시 범위를 벗어난 첫 페이지와 마지막 페이지는 별도 바로가기 버튼으로 제공하며, 중간 페이지가 생략되는 경우 Ellipsis(`…`)를 표시합니다.

```tsx
<Pagination
  page={3}
  totalPages={10}
  visiblePageCount={5}
  onPageChange={setCurrentPage}
/>
```

기본 클래스 구조는 다음과 같습니다.

```html
<nav
  class="ui-pagination ui-pagination--center"
  aria-label="페이지네이션"
>
  <ul class="ui-pagination__list">
    <li class="ui-pagination__item">
      <button
        type="button"
        class="ui-pagination__button"
        aria-label="첫 페이지"
      >
        «
      </button>
    </li>

    <li class="ui-pagination__item">
      <button
        type="button"
        class="ui-pagination__button"
        aria-label="이전 페이지"
      >
        ‹
      </button>
    </li>

    <li class="ui-pagination__item">
      <button
        type="button"
        class="ui-pagination__button is-active"
        aria-current="page"
      >
        3
      </button>
    </li>

    <li class="ui-pagination__item">
      <button
        type="button"
        class="ui-pagination__button"
        aria-label="다음 페이지"
      >
        ›
      </button>
    </li>

    <li class="ui-pagination__item">
      <button
        type="button"
        class="ui-pagination__button"
        aria-label="마지막 페이지"
      >
        »
      </button>
    </li>
  </ul>
</nav>
```

## Features

- 현재 페이지 표시
- 이전 / 다음 페이지 이동
- 첫 페이지 / 마지막 페이지 이동
- 표시할 페이지 번호 범위 자동 계산
- Ellipsis(`…`) 자동 표시
- `visiblePageCount`를 통한 표시 페이지 개수 설정
- Left / Center / Right 정렬 지원
- 첫 페이지에서 처음 / 이전 버튼 자동 비활성화 (`aria-disabled`, 포커스 유지)
- 마지막 페이지에서 다음 / 마지막 버튼 자동 비활성화 (`aria-disabled`, 포커스 유지)
- 현재 페이지 버튼을 다시 눌러도 `onPageChange` 미호출
- `aria-current`, `aria-label` 접근성 속성 지원

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `page` | `number` | - | 현재 페이지 |
| `totalPages` | `number` | - | 전체 페이지 수 |
| `onPageChange` | `(page: number) => void` | - | 페이지 변경 시 실행할 함수 |
| `visiblePageCount` | `number` | `5` | 한 번에 표시할 페이지 버튼 개수 |
| `align` | `'left' \| 'center' \| 'right'` | `'center'` | 페이지네이션 정렬 |
| `ariaLabel` | `string` | `'페이지네이션'` | `nav` 영역의 이름(`aria-label`). 한 화면에 여러 개를 쓸 때는 서로 다른 이름을 지정합니다. |
| `className` | `string` | `''` | 추가 클래스명 |

## React Component Usage

### Basic

Pagination은 현재 페이지 값을 외부 상태로 관리합니다.

```tsx
import { useState } from 'react';

function Example() {
  const [currentPage, setCurrentPage] = useState(3);

  return (
    <Pagination
      page={currentPage}
      totalPages={10}
      visiblePageCount={5}
      onPageChange={setCurrentPage}
    />
  );
}
```

---

## Page Change

페이지 버튼을 클릭하면 `onPageChange`에 이동할 페이지 번호가 전달됩니다.

```tsx
<Pagination
  page={currentPage}
  totalPages={10}
  onPageChange={(page) => {
    setCurrentPage(page);
  }}
/>
```

각 이동 버튼은 다음 값을 전달합니다.

```text
첫 페이지
→ 1

이전 페이지
→ page - 1

페이지 번호
→ 해당 pageNumber

다음 페이지
→ page + 1

마지막 페이지
→ totalPages
```

---

## Visible Page Count

`visiblePageCount`를 사용하여 한 번에 표시할 페이지 번호 개수를 설정할 수 있습니다.

기본값은 `5`입니다.

```tsx
<Pagination
  page={5}
  totalPages={20}
  visiblePageCount={5}
  onPageChange={setCurrentPage}
/>
```

현재 페이지를 중심으로 표시 범위를 계산합니다.

```text
현재 페이지: 5
visiblePageCount: 5

표시 범위:
3 4 5 6 7
```

페이지 범위가 처음이나 마지막을 벗어나는 경우 자동으로 보정됩니다.

```text
현재 페이지: 1
→ 1 2 3 4 5

현재 페이지: 10
totalPages: 10
→ 6 7 8 9 10
```

---

## First / Last Page Shortcut

현재 표시 범위에 첫 페이지 또는 마지막 페이지가 포함되지 않으면 별도 바로가기 버튼을 표시합니다.

예시:

```text
1 … 8 9 10 11 12 … 20
```

첫 페이지와 현재 표시 범위 사이에 페이지 번호가 생략되면 앞쪽 Ellipsis를 표시합니다.

마지막 표시 범위와 마지막 페이지 사이에 페이지 번호가 생략되면 뒤쪽 Ellipsis를 표시합니다.

---

## Ellipsis

Ellipsis는 이동 버튼이 아니라 생략된 페이지 범위를 표시하기 위한 UI입니다.

```html
<li
  class="ui-pagination__item ui-pagination__ellipsis"
  aria-hidden="true"
>
  <span class="ui-pagination__ellipsis-text">
    …
  </span>
</li>
```

접근성 트리에서는 불필요한 정보가 되지 않도록 `aria-hidden="true"`를 사용합니다.

## First Page State

현재 페이지가 `1`이면 첫 페이지와 이전 페이지 버튼이 비활성화됩니다.

`disabled` 대신 `aria-disabled="true"`와 `is-disabled` 클래스를 씁니다. 버튼은 포커스를 받을 수 있고(스크린리더는 "사용할 수 없음"으로 읽음), 클릭·Enter·Space를 눌러도 `onPageChange`는 호출되지 않습니다.

```tsx
<Pagination
  page={1}
  totalPages={10}
  onPageChange={setCurrentPage}
/>
```

```html
<button
  type="button"
  class="ui-pagination__button is-disabled"
  aria-label="첫 페이지"
  aria-disabled="true"
>
  «
</button>

<button
  type="button"
  class="ui-pagination__button is-disabled"
  aria-label="이전 페이지"
  aria-disabled="true"
>
  ‹
</button>
```

---

## Last Page State

현재 페이지가 `totalPages`와 같으면 다음 페이지와 마지막 페이지 버튼이 비활성화됩니다.

9페이지에서 "다음"을 눌러 마지막 페이지로 오면 그 버튼이 바로 비활성화되지만, `aria-disabled`라서 포커스는 그 버튼에 그대로 남습니다.

```tsx
<Pagination
  page={10}
  totalPages={10}
  onPageChange={setCurrentPage}
/>
```

```html
<button
  type="button"
  class="ui-pagination__button is-disabled"
  aria-label="다음 페이지"
  aria-disabled="true"
>
  ›
</button>

<button
  type="button"
  class="ui-pagination__button is-disabled"
  aria-label="마지막 페이지"
  aria-disabled="true"
>
  »
</button>
```

---

## Active Page

현재 페이지에는 `is-active` 클래스와 `aria-current="page"`가 적용됩니다.

현재 페이지 버튼은 `disabled`를 주지 않습니다. 누른 버튼이 현재 페이지가 되어도 포커스가 그 자리에 남아 키보드로 이어서 이동할 수 있습니다.
현재 페이지를 다시 눌러도 `onPageChange`는 호출되지 않습니다.

```html
<button
  type="button"
  class="ui-pagination__button is-active"
  aria-current="page"
>
  3
</button>
```

## Accessibility

- 전체 영역은 `<nav>` 요소를 사용합니다.
- `<nav>`에는 `aria-label="페이지네이션"`을 제공합니다.
- 첫 페이지 / 이전 페이지 / 다음 페이지 / 마지막 페이지 버튼에는 각 동작을 설명하는 `aria-label`을 제공합니다.
- 현재 페이지에는 `aria-current="page"`를 제공합니다.
- 현재 페이지 버튼에는 `disabled`를 주지 않습니다. `disabled`가 되면 방금 누른 버튼에서 포커스가 사라져(body로 이동) 키보드 사용자가 위치를 잃습니다. 현재 페이지에서 Enter / Space를 눌러도 `onPageChange`는 호출되지 않습니다.
- 첫 페이지에서는 첫 페이지 / 이전 페이지 버튼을, 마지막 페이지에서는 다음 페이지 / 마지막 페이지 버튼을 비활성화합니다.
  - `disabled` 대신 `aria-disabled="true"` + `is-disabled`를 씁니다. `disabled`는 버튼을 포커스 순서에서 빼므로, 방금 누른 버튼이 비활성화되면 포커스가 body로 사라집니다.
  - 비활성 상태에서 클릭·Enter·Space를 눌러도 `onPageChange`는 호출되지 않습니다.
  - HTML 클래스만 쓸 때 이동을 막는 처리는 사용하는 쪽 스크립트가 담당합니다.
- Ellipsis는 실제 조작 요소가 아니므로 `aria-hidden="true"`를 사용합니다.

현재 페이지 예시:

```html
<button
  type="button"
  class="ui-pagination__button is-active"
  aria-current="page"
>
  3
</button>
```

## Notes

- `visiblePageCount`의 기본값은 `5`입니다.
- `align`의 기본값은 `center`입니다.
- 현재 페이지를 중심으로 표시할 페이지 범위를 계산합니다.
- 표시 범위가 첫 페이지 또는 마지막 페이지를 벗어나면 자동으로 범위를 보정합니다.
- 첫 페이지와 마지막 페이지가 현재 표시 범위 밖에 있으면 별도 바로가기 버튼으로 표시합니다.
- 생략되는 페이지가 있으면 Ellipsis(`…`)를 표시합니다.
- `className`은 기본 `ui-pagination` 클래스 뒤에 추가됩니다.
- 페이지 상태는 외부에서 관리하고 `onPageChange`를 통해 변경합니다.
- 시각 예제는 `PaginationPage.tsx`에서 관리하며 Storybook에서는 `Examples`를 통해 재사용합니다.
