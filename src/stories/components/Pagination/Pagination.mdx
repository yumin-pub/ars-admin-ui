# Pagination

Pagination은 여러 페이지의 데이터를 탐색하기 위한 컴포넌트입니다.

현재 페이지를 기준으로 페이지 번호를 표시하며, 첫 페이지, 이전 페이지, 다음 페이지, 마지막 페이지로 이동할 수 있습니다.

---

## Features

- 현재 페이지 표시
- 이전 / 다음 이동
- 첫 페이지 / 마지막 페이지 이동
- 페이지 개수 자동 계산
- Ellipsis(...) 자동 표시
- Left / Center / Right 정렬 지원
- 접근성(aria-current, aria-label) 지원

## Props

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| page | number | - | 현재 페이지 |
| totalPages | number | - | 전체 페이지 수 |
| visiblePageCount | number | 5 | 한 번에 표시할 페이지 버튼 개수 |
| align | `'left' \| 'center' \| 'right'` | `'center'` | 페이지네이션 정렬 |
| className | string | `''` | 추가 클래스명 |
| onPageChange | `(page: number) => void` | - | 페이지 변경 이벤트 |
